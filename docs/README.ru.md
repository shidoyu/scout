Встроенный WebSearch в Claude Code возвращает фрагменты длиной 125 символов и полагается исключительно на совпадение ключевых слов. Для простых поисков этого достаточно, но настоящее исследование требует проектирования запросов, оценки источников и маршрутизации с учётом конфиденциальности.

scout думает, прежде чем искать.

## Быстрый старт

API-ключи не нужны. Никаких изменений среды. Установите и сразу попробуйте:

**1. Добавьте маркетплейс** (одноразово):

```bash
claude plugin marketplace add shidoyu/scout
```

**2. Установите**:

```bash
claude plugin install scout@shidoyu-scout
```

**3. Перезагрузите плагины** (введите в Claude Code):

```
/mcp
```

Затем спросите Claude:

```text
/scout:search Ищу что-то вроде Git blame, но для отслеживания проектных решений
```

scout преобразует эту расплывчатую концепцию в правильный термин (ADR — Architecture Decision Records), выполнит поиск в нескольких движках оптимизированными запросами, оценит качество источников и вернёт ответ с Research Trail, показывающим, как именно он к нему пришёл.

## Что делает scout

### Находит концепции, которые вы ещё не можете назвать

> «Я знаю, что такая концепция существует — что-то о фиксации причин каждого проектного решения — но не знаю, как она называется»

scout превращает размытые идеи в точную терминологию и достигает первоисточников.

### Пробивается сквозь SEO-шум

> «На что реально стоит мигрировать с Terraform — не спонсорские списки, а настоящие истории миграции»

Предварительное исследование помогает получить правильную лексику, после чего целенаправленные запросы обходят контент-фермы.

### Попадает напрямую в официальную документацию

> «Как настроить middleware в Next.js App Router?»

scout сначала проверяет [Context7](https://github.com/upstash/context7) на наличие индексированной официальной документации — если ответ есть там, веб-поиск не нужен.

### Читает любую веб-страницу

> «Загрузи и подытожь https://docs.anthropic.com/en/docs/claude-code»

Загрузка с учётом конфиденциальности: публичные страницы проходят через облачные API, конфиденциальные страницы остаются на вашем компьютере.

## Уровни настройки

scout работает сразу после установки. Каждый уровень добавляет возможности — все необязательные и обратимые.

### Уровень 1: Встроенный поиск (по умолчанию)

Использует WebSearch в Claude Code. Настройка не требуется. Это то, что вы получаете сразу после установки.

### Уровень 2: Официальная документация + более чистая загрузка

Добавьте [Context7](https://github.com/upstash/context7) для прямого доступа к документации библиотек/фреймворков и [Jina Reader](https://jina.ai) для более чистого чтения страниц. Context7 не требует API-ключа; необязательный ключ для Jina увеличивает лимиты.

### Уровень 3: Семантический поиск

Добавьте [Exa](https://exa.ai) для поиска на основе значения — находит релевантные страницы, даже когда вы не знаете правильных ключевых слов. Базовый семантический поиск работает на бесплатном плане; API-ключ открывает расширенные функции.

### Уровень 4: Локальный браузер

Добавьте [Playwright](https://playwright.dev) для страниц, рендерящихся JavaScript, и конфиденциальных URL-адресов, которые не должны покидать ваш компьютер. Скачивает Chromium (~200МБ).

**Запустите `/scout:setup`, чтобы интерактивно пройти каждый уровень.** Каждый шаг точно показывает, что будет добавлено в конфигурацию, прежде чем будут внесены какие-либо изменения. Можно запускать повторно в любое время для добавления или обновления инструментов.

## Навыки

| Навык | Назначение |
|---|---|
| `/scout:search` | Мультидвижковый веб-поиск с проектированием запросов, оценкой источников и автоматическим повторным поиском |
| `/scout:fetch` | Загрузка содержимого URL с автоматической классификацией конфиденциальности |
| `/scout:setup` | Интерактивное руководство по настройке поисковых движков и инструментов загрузки |

### Research Trail

Каждый поиск завершается структурированной записью, показывающей, как scout пришёл к ответу:

```
🔍 Research Trail
───────────────────────────────
Query:           ваш исходный вопрос
Designed queries: оптимизированные запросы, которые scout фактически выполнил
Sources:         URL-адреса с уровнем надёжности (🟢 первоисточники / 🟡 вторичные / ⚪ третичные)
Re-searches:     дополнительные поиски и их причины
Confidence:      High / Medium / Low с обоснованием
```

## Конфиденциальность

scout классифицирует URL-адреса на три уровня перед загрузкой:

| Классификация | Маршрутизация | Примеры |
|---|---|---|
| **Публичные** | Облачные API (Jina Reader / WebFetch) | Блоги, документация, публичные репозитории GitHub |
| **Конфиденциальные** | Только локальный Playwright | localhost, внутренние вики, панели администрирования |
| **С аутентификацией** | Chrome DevTools (сессия браузера) | Notion, Slack, страницы после OAuth-аутентификации |

Эта классификация основана на оценке LLM, а не на системном принуждении. Рассматривайте её как маршрутизацию по принципу наилучших усилий. Для высокочувствительных данных проверьте классификацию перед продолжением.

**Конфиденциальные URL-адреса никогда не отправляются во внешние API, даже в случае неудачи** — система не переключается на облачные инструменты для конфиденциальных страниц.

<details>
<summary>Настройка Chrome DevTools (для страниц с аутентификацией)</summary>

Для загрузки страниц, требующих входа (OAuth, SaaS-панели), запустите Chrome в режиме отладки:

macOS:

```bash
open -a "Google Chrome" --args --remote-debugging-port=9222
```

Linux:

```bash

```
</details>

<details>
<summary>Примечание о профиле браузера</summary>

Модуль загрузки на основе Playwright использует постоянный профиль браузера (`tools/.chrome-profile/`), в котором могут накапливаться cookies и данные сессий. Этот каталог исключён из Git через `.gitignore`, но может быть скопирован инструментами резервного копирования. Если вы загружаете конфиденциальные страницы, периодически удаляйте его.
</details>

## Удаление

Две команды удаляют всё. Без остатков.

Удалите плагин (очищает кеш, конфигурацию и данные состояния):

```bash
claude plugin uninstall scout@shidoyu-scout
```

Удалите Context7, если вы добавили его через scout:setup (область пользователя — удаляется из всех проектов):

```bash
claude mcp remove context7
```

## Требования

- **Claude Code** (обязательно)
- `jq` (только для диагностики настройки)
- Python 3.10+ (только для локальной загрузки через Playwright)
- `npm`/`npx` (только для MCP-сервера Chrome DevTools)

## Безопасность

API-ключи хранятся в файле `.mcp.json` в каталоге плагина.
**Не коммитьте `.mcp.json` в Git.** Шаблон `.mcp.json.dist` безопасен для распространения.
