WebSearch ที่มีอยู่ใน Claude Code ส่งคืนข้อความสั้นเพียง 125 ตัวอักษร และอาศัยเพียงการจับคู่คำสำคัญ สำหรับการค้นหาทั่วไปนั้นเพียงพอ แต่สำหรับงานวิจัยจริงจัง คุณต้องการการออกแบบคิวรี การประเมินแหล่งข้อมูล และการกำหนดเส้นทางที่คำนึงถึงความเป็นส่วนตัว

scout คิดก่อนค้นหา

## เริ่มต้นอย่างรวดเร็ว

ไม่ต้องใช้ API key ไม่ต้องเปลี่ยนแปลง environment ติดตั้งแล้วลองได้เลย:

**1. เพิ่ม marketplace** (ครั้งเดียว):

```bash
claude plugin marketplace add shidoyu/scout
```

**2. ติดตั้ง**:

```bash
claude plugin install scout@shidoyu-scout
```

**3. โหลดปลั๊กอินใหม่** (พิมพ์ใน Claude Code):

```
/mcp
```

จากนั้นถาม Claude:

```text
/scout:search ฉันต้องการอะไรคล้าย Git blame แต่สำหรับการตัดสินใจด้านการออกแบบ
```

scout จะเปลี่ยนแนวคิดที่คลุมเครือนี้ให้เป็นคำศัพท์ที่ถูกต้อง (ADR — Architecture Decision Records) ค้นหาด้วยคิวรีที่ปรับแต่งแล้วในหลายเครื่องมือ ประเมินคุณภาพแหล่งข้อมูล และส่งคืนคำตอบพร้อม Research Trail ที่แสดงให้เห็นว่าไปถึงคำตอบได้อย่างไร

## scout ทำอะไรได้บ้าง

### ค้นหาแนวคิดที่คุณยังไม่รู้ชื่อ

> "ฉันรู้ว่ามีแนวคิดนี้อยู่ — เกี่ยวกับการบันทึกเหตุผลว่าทำไมถึงตัดสินใจออกแบบแบบนั้น — แต่ไม่รู้ว่าเรียกว่าอะไร"

scout แปลงไอเดียที่คลุมเครือเป็นศัพท์เฉพาะที่แม่นยำ และเข้าถึงแหล่งข้อมูลปฐมภูมิ

### ฝ่า noise ของ SEO

> "จริงๆ แล้วควรย้ายจาก Terraform ไปที่ไหน — ไม่ใช่รายการที่มีสปอนเซอร์ แต่เป็นประสบการณ์ย้ายจริง"

การวิจัยเบื้องต้นจะหาคำศัพท์ที่ถูกต้องก่อน จากนั้นคิวรีที่ตรงจุดจะข้ามผ่าน content farm

### เข้าถึงเอกสารทางการโดยตรง

> "จะตั้งค่า middleware ใน Next.js App Router อย่างไร?"

scout ตรวจสอบ [Context7](https://github.com/upstash/context7) ก่อนเพื่อหาเอกสารทางการที่จัดทำดัชนีไว้แล้ว — ไม่ต้องค้นหาเว็บเลยถ้าคำตอบอยู่ที่นั่น

### อ่านหน้าเว็บใดก็ได้

> "ดึงและสรุป https://docs.anthropic.com/en/docs/claude-code"

การดึงข้อมูลที่คำนึงถึงความเป็นส่วนตัว: หน้าสาธารณะผ่าน API บนคลาวด์ หน้าลับอยู่บนเครื่องของคุณ

## ระดับการตั้งค่า

scout ทำงานได้ทันทีหลังติดตั้ง แต่ละระดับเพิ่มความสามารถ — ทั้งหมดเป็นทางเลือก ทั้งหมดย้อนกลับได้

### ระดับ 1: การค้นหาในตัว (ค่าเริ่มต้น)

ใช้ WebSearch ของ Claude Code ไม่ต้องตั้งค่าใดๆ นี่คือสิ่งที่ได้มาตั้งแต่แรก

### ระดับ 2: เอกสารทางการ + การดึงข้อมูลที่สะอาดขึ้น

เพิ่ม [Context7](https://github.com/upstash/context7) สำหรับเข้าถึงเอกสาร library/framework โดยตรง และ [Jina Reader](https://jina.ai) สำหรับอ่านหน้าเว็บที่สะอาดขึ้น Context7 ไม่ต้องใช้ API key; key เสริมสำหรับ rate limit ของ Jina

### ระดับ 3: การค้นหาเชิงความหมาย

เพิ่ม [Exa](https://exa.ai) สำหรับค้นหาตามความหมาย — หาหน้าที่เกี่ยวข้องได้แม้ไม่รู้คำสำคัญที่ถูกต้อง การค้นหาเชิงความหมายพื้นฐานใช้ได้ฟรี; API key ปลดล็อกฟีเจอร์ขั้นสูง

### ระดับ 4: เบราว์เซอร์ในเครื่อง

เพิ่ม [Playwright](https://playwright.dev) สำหรับหน้าที่เรนเดอร์ด้วย JavaScript และ URL ลับที่ไม่ควรออกจากเครื่องของคุณ ต้องดาวน์โหลด Chromium (~200MB)

**รัน `/scout:setup` เพื่อตั้งค่าแต่ละระดับแบบโต้ตอบ** ทุกขั้นตอนจะแสดงให้เห็นว่าจะเพิ่มอะไรในการตั้งค่าก่อนทำการเปลี่ยนแปลง รันซ้ำได้ทุกเมื่อเพื่อเพิ่มหรืออัปเดตเครื่องมือ

## ทักษะ

| ทักษะ | วัตถุประสงค์ |
|---|---|
| `/scout:search` | ค้นหาเว็บหลายเครื่องมือพร้อมออกแบบคิวรี ประเมินแหล่งข้อมูล และค้นหาซ้ำอัตโนมัติ |
| `/scout:fetch` | ดึงเนื้อหา URL พร้อมจำแนกความเป็นส่วนตัวอัตโนมัติ |
| `/scout:setup` | การตั้งค่าแบบโต้ตอบสำหรับเครื่องมือค้นหาและเครื่องมือดึงข้อมูล |

### Research Trail

ทุกการค้นหาจบลงด้วยร่องรอยที่มีโครงสร้าง แสดงให้เห็นว่า scout ไปถึงคำตอบได้อย่างไร:

```
🔍 Research Trail
───────────────────────────────
Query:           คำถามดั้งเดิมของคุณ
Designed queries: คิวรีที่ปรับแต่งแล้วที่ scout รันจริง
Sources:         URL พร้อมระดับความน่าเชื่อถือ (🟢 ปฐมภูมิ / 🟡 ทุติยภูมิ / ⚪ ตติยภูมิ)
Re-searches:     การค้นหาเพิ่มเติมและเหตุผล
Confidence:      High / Medium / Low พร้อมเหตุผล
```

## ความเป็นส่วนตัว

scout จำแนก URL เป็นสามระดับก่อนดึงข้อมูล:

| การจำแนก | การกำหนดเส้นทาง | ตัวอย่าง |
|---|---|---|
| **สาธารณะ** | API บนคลาวด์ (Jina Reader / WebFetch) | บล็อก เอกสาร repo สาธารณะของ GitHub |
| **ลับ** | Playwright ในเครื่องเท่านั้น | localhost วิกิภายใน แผงผู้ดูแลระบบ |
| **ผ่านการยืนยันตัวตน** | Playwright CDP | Notion, Slack หน้าหลัง OAuth |

การจำแนกนี้อิงตามการตัดสินใจของ LLM ไม่ใช่การบังคับของระบบ ถือเป็นการกำหนดเส้นทางแบบ best-effort สำหรับข้อมูลที่มีความอ่อนไหวสูง ตรวจสอบการจำแนกก่อนดำเนินการ

**URL ลับจะไม่ถูกส่งไปยัง API ภายนอกเด็ดขาด แม้ในกรณีที่ล้มเหลว** — ระบบจะไม่ย้อนกลับไปใช้เครื่องมือคลาวด์สำหรับหน้าลับ

<details>
<summary>การตั้งค่าโหมดดีบัก Chrome (สำหรับหน้าที่ผ่านการยืนยันตัวตน)</summary>

เพื่อดึงหน้าที่ต้องเข้าสู่ระบบ (OAuth, แดชบอร์ด SaaS) ให้เปิด Chrome ในโหมดดีบัก. Chrome 146+ requires a separate `--user-data-dir`:

macOS:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --remote-debugging-port=9222 \
  --user-data-dir=$HOME/.chrome-debug
```

Linux:

```bash
google-chrome --remote-debugging-port=9222 --user-data-dir=$HOME/.chrome-debug
```

On first launch with a new `--user-data-dir`, you'll need to log in to your accounts again. After that, sessions persist across restarts.
</details>

<details>
<summary>หมายเหตุโปรไฟล์เบราว์เซอร์</summary>

ตัวดึงข้อมูลที่ใช้ Playwright ใช้โปรไฟล์เบราว์เซอร์แบบถาวร (`tools/.chrome-profile/`) ซึ่งอาจสะสมคุกกี้และข้อมูลเซสชัน ไดเรกทอรีนี้ถูกยกเว้นจาก Git ผ่าน `.gitignore` แต่อาจถูกคัดลอกโดยเครื่องมือสำรองข้อมูล หากคุณดึงหน้าลับ ให้ลบเป็นระยะๆ
</details>

## ถอนการติดตั้ง

สองคำสั่งเพื่อลบทุกอย่าง ไม่มีสิ่งตกค้าง

ลบปลั๊กอิน (ล้าง cache การตั้งค่า และข้อมูลสถานะ):

```bash
claude plugin uninstall scout@shidoyu-scout
```

ลบ Context7 หากคุณเพิ่มผ่าน scout:setup (ขอบเขตผู้ใช้ — ลบจากทุกโปรเจกต์):

```bash
claude mcp remove context7
```

## ข้อจำกัดความรับผิดชอบ

ปลั๊กอินนี้ให้บริการ "ตามสภาพ" ภายใต้ MIT License โดยไม่มีการรับประกันใดๆ

**API ภายนอก** ปลั๊กอินนี้พึ่งพา API ของบุคคลที่สาม (Exa, Jina AI และอื่นๆ) ผู้เขียนไม่รับประกันความพร้อมใช้งาน ความถูกต้อง ราคา หรือความต่อเนื่องของบริการเหล่านี้ และไม่รับผิดชอบต่อค่าใช้จ่ายที่เกิดจากการใช้งาน API

**การจัดการ API Key** คุณเป็นผู้รับผิดชอบแต่เพียงผู้เดียวในการรับ รักษาความปลอดภัย และจัดการ API key ของคุณ รวมถึงการปฏิบัติตามข้อกำหนดการให้บริการของผู้ให้บริการแต่ละราย

**การจำแนกเนื้อหา** การจำแนกความเป็นส่วนตัวของ URL อิงตามการตัดสินใจของ LLM และอาจมีข้อผิดพลาด อย่าพึ่งพาสิ่งนี้เป็นมาตรการป้องกันเพียงอย่างเดียวสำหรับข้อมูลที่อ่อนไหว

**การดึงเว็บและระบบอัตโนมัติของเบราว์เซอร์** ปลั๊กอินนี้รวมเครื่องมือระบบอัตโนมัติของเบราว์เซอร์แบบ headless ผ่าน Playwright คุณเป็นผู้รับผิดชอบในการตรวจสอบว่าการใช้งานของคุณเป็นไปตามข้อกำหนดการให้บริการของเว็บไซต์เป้าหมาย นโยบาย robots.txt และกฎหมายที่บังคับใช้

**เซิร์ฟเวอร์ MCP** ปลั๊กอินนี้เชื่อมต่อกับเซิร์ฟเวอร์ MCP ของบุคคลที่สาม ผู้เขียนไม่ได้ควบคุม ตรวจสอบ หรือรับประกันพฤติกรรมหรือความปลอดภัยของเซิร์ฟเวอร์เหล่านี้
