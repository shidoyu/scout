<h1 align="center">scout</h1>

<p align="center">

---

Вбудований WebSearch у Claude Code повертає фрагменти довжиною 125 символів і покладається лише на збіг ключових слів. Для простих пошуків цього достатньо, але справжні дослідження потребують проєктування запитів, оцінки джерел та маршрутизації з урахуванням конфіденційності.

scout думає, перш ніж шукати.

## Швидкий старт

API-ключі не потрібні. Жодних змін середовища. Встановіть і одразу спробуйте:

**1. Додайте маркетплейс** (одноразово):

```bash
claude plugin marketplace add shidoyu/scout
```

**2. Встановіть**:

```bash
claude plugin install scout@shidoyu-scout
```

**3. Перезавантажте плагіни** (введіть у Claude Code):

```
/mcp
```

Потім запитайте Claude:

```text
/scout:search Шукаю щось на кшталт Git blame, але для відстеження проєктних рішень
```

scout перетворить цю розпливчасту концепцію на правильний термін (ADR — Architecture Decision Records), здійснить пошук у кількох пошукових системах оптимізованими запитами, оцінить якість джерел і поверне відповідь із Research Trail, що точно показує, як він до неї дійшов.

## Що робить scout

### Знаходить концепції, які ви ще не можете назвати

> «Я знаю, що така концепція існує — щось про фіксацію причин кожного проєктного рішення — але не знаю, як вона називається»

scout перетворює нечіткі ідеї на точну термінологію та досягає першоджерел.

### Пробивається крізь SEO-шум

> «На що насправді варто мігрувати з Terraform — не спонсоровані списки, а реальні історії міграції»

Попереднє дослідження допомагає отримати правильну лексику, а потім цілеспрямовані запити обходять контент-ферми.

### Потрапляє прямо до офіційної документації

> «Як налаштувати middleware у Next.js App Router?»

scout спочатку перевіряє [Context7](https://github.com/upstash/context7) на наявність проіндексованої офіційної документації — якщо відповідь є там, веб-пошук не потрібен.

### Читає будь-яку веб-сторінку

> «Завантаж і підсумуй https://docs.anthropic.com/en/docs/claude-code»

Завантаження з урахуванням конфіденційності: публічні сторінки проходять через хмарні API, конфіденційні сторінки залишаються на вашому комп'ютері.

## Рівні налаштування

scout працює одразу після встановлення. Кожен рівень додає можливості — усі необов'язкові та зворотні.

### Рівень 1: Вбудований пошук (за замовчуванням)

Використовує WebSearch у Claude Code. Налаштування не потрібне. Це те, що ви отримуєте одразу після встановлення.

### Рівень 2: Офіційна документація + чистіше завантаження

Додайте [Context7](https://github.com/upstash/context7) для прямого доступу до документації бібліотек/фреймворків та [Jina Reader](https://jina.ai) для чистішого читання сторінок. Context7 не потребує API-ключа; необов'язковий ключ для Jina підвищує ліміти.

### Рівень 3: Семантичний пошук

Додайте [Exa](https://exa.ai) для пошуку на основі значення — знаходить релевантні сторінки навіть тоді, коли ви не знаєте правильних ключових слів. Базовий семантичний пошук працює на безкоштовному плані; API-ключ відкриває розширені функції.

### Рівень 4: Локальний браузер

Додайте [Playwright](https://playwright.dev) для сторінок, що рендеряться JavaScript, та конфіденційних URL-адрес, які не повинні залишати ваш комп'ютер. Завантажує Chromium (~200МБ).

**Запустіть `/scout:setup`, щоб інтерактивно пройти кожен рівень.** Кожен крок точно показує, що буде додано до конфігурації, перш ніж буде внесено будь-які зміни. Можна запускати повторно в будь-який час для додавання або оновлення інструментів.

## Навички

| Навичка | Призначення |
|---|---|
| `/scout:search` | Багатодвигунковий веб-пошук із проєктуванням запитів, оцінкою джерел та автоматичним повторним пошуком |
| `/scout:fetch` | Завантаження вмісту URL з автоматичною класифікацією конфіденційності |
| `/scout:setup` | Інтерактивний посібник з налаштування пошукових систем та інструментів завантаження |

### Research Trail

Кожен пошук завершується структурованим записом, що показує, як scout дійшов до відповіді:

```
🔍 Research Trail
───────────────────────────────
Query:           ваше оригінальне запитання
Designed queries: оптимізовані запити, які scout фактично виконав
Sources:         URL-адреси з рівнем надійності (🟢 першоджерела / 🟡 вторинні / ⚪ третинні)
Re-searches:     додаткові пошуки та їх причини
Confidence:      High / Medium / Low з обґрунтуванням
```

## Конфіденційність

scout класифікує URL-адреси на три рівні перед завантаженням:

| Класифікація | Маршрутизація | Приклади |
|---|---|---|
| **Публічні** | Хмарні API (Jina Reader / WebFetch) | Блоги, документація, публічні репозиторії GitHub |
| **Конфіденційні** | Лише локальний Playwright | localhost, внутрішні вікі, адмін-панелі |
| **З автентифікацією** | Chrome DevTools (сесія браузера) | Notion, Slack, сторінки після OAuth-автентифікації |

Ця класифікація базується на оцінці LLM, а не на системному примусі. Розглядайте її як маршрутизацію за принципом найкращих зусиль. Для високочутливих даних перевірте класифікацію перед продовженням.

**Конфіденційні URL-адреси ніколи не надсилаються до зовнішніх API, навіть у разі невдачі** — система не переключається на хмарні інструменти для конфіденційних сторінок.

<details>
<summary>Налаштування Chrome DevTools (для сторінок з автентифікацією)</summary>

Для завантаження сторінок, що вимагають входу (OAuth, SaaS-панелі), запустіть Chrome у режимі налагодження:

macOS:

```bash
open -a "Google Chrome" --args --remote-debugging-port=9222
```

Linux:

```bash
google-chrome --remote-debugging-port=9222
```
</details>

<details>
<summary>Примітка щодо профілю браузера</summary>

Модуль завантаження на основі Playwright використовує постійний профіль браузера (`tools/.chrome-profile/`), у якому можуть накопичуватися файли cookie та дані сесій. Цей каталог виключений із Git через `.gitignore`, але може бути скопійований інструментами резервного копіювання. Якщо ви завантажуєте конфіденційні сторінки, періодично видаляйте його.
</details>

## Видалення

Дві команди видаляють все. Без залишків.

Видаліть плагін (очищує кеш, конфігурацію та дані стану):

```bash
claude plugin uninstall scout@shidoyu-scout
```

Видаліть Context7, якщо ви додали його через scout:setup (область користувача — видаляється з усіх проєктів):

```bash
claude mcp remove context7
```

**Не комітьте `.mcp.json` у Git.** Шаблон `.mcp.json.dist` безпечний для розповсюдження.

## Застереження

Цей плагін надається «як є» за ліцензією MIT, без будь-яких гарантій.

**Зовнішні API.** Цей плагін використовує API третіх сторін (Exa, Jina AI та інші). Автор не гарантує доступність, точність, ціноутворення чи безперервність роботи цих сервісів і не несе відповідальності за витрати, пов'язані з використанням API.

**Управління API-ключами.** Отримання, захист та управління власними API-ключами, а також дотримання умов обслуговування кожного постачальника — це виключно ваша відповідальність.

**Класифікація контенту.** Класифікація конфіденційності URL-адрес базується на оцінці LLM і може містити помилки. Не покладайтеся на неї як на єдиний засіб захисту конфіденційної інформації.

**Веб-завантаження та автоматизація браузера.** Цей плагін містить інструменти для автоматизації безголового браузера через Playwright та Chrome DevTools. Ви несете відповідальність за дотримання умов обслуговування цільових сайтів, політик robots.txt та чинного законодавства.

**MCP-сервери.** Цей плагін підключається до MCP-серверів третіх сторін. Автор не контролює, не перевіряє та не гарантує поведінку й безпеку цих серверів.
